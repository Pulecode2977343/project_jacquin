Este documento constituye el pilar técnico definitivo de la plataforma. Ha sido diseñado bajo una metodología de análisis orientado a objetos, garantizando que cada componente de software responda a una necesidad pedagógica real de la academia.

Requerimientos

Análisis de los pilares funcionales y de calidad del sistema.

Funcional

RF-01: Autenticación

Acceso diferenciado por perfiles (Admin, Docente, Estudiante) con niveles de permiso granulares.

Funcional

RF-02: Inscripción

Motor de inscripción automatizada que valida disponibilidad de cupos en tiempo real.

Calidad

RNF-01: BCRYPT

Seguridad de grado bancario para el almacenamiento de contraseñas de usuario.

Calidad

RNF-04: API REST

Backend desacoplado que permite escalar a aplicaciones móviles nativas sin cambios de lógica.

Arquitectura y API

Frontend Vanilla

HTML5, CSS3 y JS ES6+. Sin dependencias externas pesadas para asegurar compatibilidad total.

Backend Desacoplado

API REST nativa en PHP 8 que entrega datos en formato JSON puro.

Desglose de Carpetas (Didáctico)

1. config/

El "cordón umbilical" con la base de datos MySQL (db.php).

2. middleware/

El vigilante que frena accesos no autorizados antes de tocar el código.

3. helpers/

Los cerebros auxiliares: validación de conflictos horaríos y envío de correos.

Raíz / Endpoints

Scripts especialistas (login.php, etc.) optimizados para ejecución veloz.
