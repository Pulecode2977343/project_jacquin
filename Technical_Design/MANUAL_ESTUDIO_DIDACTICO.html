Guía de Ingeniería Desglosada (Sin Jerga)

1. El Concepto Principal

¿Qué hace el sistema?

La Oficina Virtual Académica

Es una plataforma que ayuda a la academia de música a funcionar sin caos. Imagina un recepcionista, un bibliotecario y un vigilante que trabajan 24/7 para que los horarios no se crucen y nadie entre donde no debe.

2. Las Tres Piezas Clave

Todo el software se divide en tres partes que trabajan en equipo:

La Cara (Frontend)

Lo que el usuario ve: botones, colores y fotos. Es la carpeta web_page.

El Cerebro (API)

La parte que piensa, calcula horarios y decide. Es la carpeta jacquin_api.

El Archivo (Base de Datos)

El libro gigante donde se anotan nombres, notas y horarios para siempre.

3. ¿Qué hay dentro del Cerebro?

Desarmamos la carpeta de la API pieza por pieza:

Capa de Enchufe

Configuración (config/)

Es el archivo que le dice al sistema la dirección y la contraseña para poder entrar al "Archivo" (Base de Datos). Sin esto, el cerebro no recuerda nada.

Capa de Guardia

Seguridad (middleware/)

Es el vigilante que revisa el carnet. Si alguien intenta entrar a un área protegida (como las notas) sin permiso, este vigilante lo saca antes de que toque nada.

Capa de Asesores

Herramientas (helpers/)

Son expertos que el cerebro llama para tareas difíciles:

  • Asesor de Horarios: El genio matemático que asegura que un alumno no esté en dos clases a la vez.
  • Asesor de Mensajes: Se encarga de enviar correos automáticos.

Bodega Pública (public/)

Donde se guardan las fotos de perfil y las imágenes que todos ven en la web.

Herramientas Externas (vendor/)

Herramientas ya hechas por otros expertos (como el sistema para enviar emails). No se tocan.

4. ¿Cómo fluye la información?

Ejemplo: Cuando un alumno se inscribe.

  • Petición: El alumno hace clic en "Inscribirme" desde la web.
  • Verificación: El cerebro le pregunta al Asesor matemático por choques de horarios.
  • Respuesta: Si el horario está libre, se da permiso. Si está ocupado, se envía un aviso.
  • Guardado: Si todo está bien, se anota el nombre en el "Archivo" de forma permanente.
Nota sobre Seguridad: Las contraseñas se guardan como "Huellas Digitales" (Hashes). Nadie puede leer tu contraseña real, ni siquiera el dueño del sistema.

5. Resumen para la Defensa

Este sistema fue diseñado para separar la **estética** (el diseño moderno) de la **lógica** (los cálculos y datos). Esto lo hace seguro, rápido y fácil de mejorar en el futuro. Es una plataforma profesional lista para la vida real.
