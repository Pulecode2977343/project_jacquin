Informe de Buenas Prácticas de Calidad de Software

Aplicación documentada en el proyecto "Academia Musical Jacquin"

Contexto del Proyecto: Plataforma web educativa diseñada para la promoción, inscripción y gestión de cursos musicales (Piano, Guitarra, Técnica Vocal), facilitando el acceso a la formación artística.

1. Introducción

Este documento técnico describe la implementación de estándares de calidad en el desarrollo del portal web Academia Musical Jacquin. Se detalla cómo las decisiones de arquitectura, codificación y diseño cumplen con los requisitos de la norma ISO/IEC 25000, asegurando una experiencia de usuario óptima y un código mantenible.

2. Modelo de Calidad (ISO/IEC 25000)

Se han priorizado los siguientes atributos de calidad para el entorno educativo:

  • Usabilidad: Interfaces intuitivas para estudiantes de todas las edades. Diseño claro y accesible.
  • Eficiencia de Desempeño: Optimización de recursos multimedia y **reducción de latencia en API** (eliminación de N+1 consultas en el motor de cursos).
  • Portabilidad: Adaptabilidad (Responsive Design) para acceso desde móviles, tablets y escritorios.
  • Mantenibilidad: Centralización de lógica académica y eliminación de conflictos de scripts redundantes.

3. Implementación de Buenas Prácticas

3.1. Estructura Semántica (HTML5)

Se utiliza HTML5 semántico para mejorar la accesibilidad (lectores de pantalla) y el posicionamiento SEO, fundamental para la visibilidad de la academia.

3.2. Diseño Responsivo y CSS Moderno

Implementación de CSS Grid y Flexbox para garantizar que el contenido se adapte fluidamente a cualquier dispositivo, cumpliendo con el atributo de Portabilidad.

/* Diseño adaptable para tarjetas de cursos */ .course-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 2rem; } @media (max-width: 768px) { .nav-menu { display: none; } /* Menú móvil */ }

3.3. Optimización de Multimedia

Dado el enfoque visual y artístico, se aplican técnicas de carga diferida (Lazy Loading) y formatos de imagen modernos (WebP) para asegurar tiempos de carga rápidos.

  • Uso de atributo loading="lazy" en iframes y galerías.
  • Texto alternativo (alt) descriptivo en todas las imágenes para accesibilidad.
  • Optimización de Consultas SQL: Reducción de latencia mediante la consolidación de 3 consultas SQL agrupadas en lugar de peticiones iterativas (N+1), garantizando estabilidad en entornos de red limitada (ej: túneles zrok).

4. Herramientas de Aseguramiento (QA)

El flujo de trabajo incluye validaciones automáticas y manuales:

  • Validación W3C: Verificación de sintaxis HTML/CSS para asegurar compatibilidad estándar.
  • Lighthouse (Google): Auditorías periódicas de rendimiento, accesibilidad y SEO.
  • Refactorización de Código: Eliminación de variables no declaradas y conflictos de scripts para asegurar la robustez de la UI (V7).
  • Control de Versiones: Auditoría de cambios estéticos para cumplir con el Brandbook V2 (Botones "Dignos").
