ANÁLISIS TÉCNICO

1. ¿Se usó la técnica de componente en el proyecto?

Respuesta: PARCIALMENTE SÍ.

Se detectó el componente <jam-header> ubicado en js/components/Header.js. Este es un Web Component nativo.

El Problema de las Sombras:

El desarrollador incrustó (hardcoded) el código SVG dentro del Javascript (línea 160 aprox) pero eliminó las etiquetas <defs> y <linearGradient>, reemplazándolas por un color plano (#FFFEFF).

Por eso el logo en la web se ve plano, mientras que el archivo logo_hr_jam.svg original tiene volumen y degradados.
