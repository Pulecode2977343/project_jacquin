24022026ENROLL 24 Feb 2026 — Modal de Programas & Flujo de Inscripción

Instrucción Original

"Audita la lógica y el flujo perdido de la sección de nuestros programas. Cuando se cliquea en un programa ofertado, no se despliega el modal. Maneja todos los casos: logueado, no logueado, no registrado, intento de inscripción y recuperación del hilo del proceso. Realiza el llamado de los agentes, verifica lo que en su momento se programó y quedó desconectado, readapta si existe, crea si no existe, evitar archivos duplicados."

Causa Raíz Identificada

Conflicto de paradigma: Vanilla JS vs. React SPA. programs_carousel.js (472 líneas) implementa toda la lógica de modal/inscripción en Vanilla JS con document.addEventListener('DOMContentLoaded', ...), pero ese archivo nunca fue incluido en index.html de la SPA. La línea onClick={() => window.openProgramModal && window.openProgramModal(key)} en Programs.jsx cortocircuitaba silenciosamente porque window.openProgramModal era undefined.

Bugs secundarios confirmados:

  • Post-login: navigate('/#programas') no dispara DOMContentLoaded en SPA → recovery de intent nunca ocurría.
  • Field mismatch: programs_carousel.js:294 usaba c.name pero la API get_courses.php retorna c.course_name.

Solución Implementada

  • ProgramModal.jsx (nuevo) — Modal React con imagen, ícono, título, descripción, beneficios y botón "Inscribirme".
  • ScheduleModal.jsx (nuevo) — Carga cursos, hace match por nombre, carga horarios, permite selección y llama ApiService.requestEnrollment(). Estados: loading → select → success / error.
  • AuthPromptModal.jsx (nuevo) — Overlay para visitantes. Guarda intent en sessionStorage antes de navegar a /login o /registro.
  • Programs.jsx (refactorizado) — State selectedKey + modalStep. Handler openProgram(). Recovery via useLocation() cuando location.state.recoverEnrollment === true.
  • Login.jsx (corregido) — navigate('/', { state: { recoverEnrollment: true } }) reemplaza navigate('/#programas').
  • Campo c.course_name usado correctamente en ScheduleModal.jsx.

Flujos Cubiertos

  • Autenticado: Click → ProgramModal → "Inscribirme" → ScheduleModal → selección → requestEnrollment() → Success.
  • Visitante: Click → ProgramModal → "Inscribirme" → sessionStorage guardado → AuthPromptModal → Login → navigate con state → ScheduleModal auto-abierto.
  • Visitante → Registro: AuthPromptModal → /registro (curso preseleccionado por pending_enrollment_title) → Login → recovery.
  • Sin horarios / sin curso: ScheduleModal muestra estado de error con mensaje amigable.

Archivos Modificados

  • src/components/ScheduleModal.jsx — CREADO
  • src/components/AuthPromptModal.jsx — CREADO
  • src/components/Programs.jsx — REFACTORIZADO
