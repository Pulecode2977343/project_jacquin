✔ 1. Corrección y Optimización de Subida de Avatares Completado

  • 📷

    Centralización de Directorio

    Se modificó el archivo admin_upload_avatar.php para utilizar de manera nativa la clase de utilidad PathHelper. El directorio físico unificado de uploads para perfil quedó fijado en ruta segura y pública dentro de jacquin_api/public/uploads/avatars/, evitando conflictos entre la SPA y el entorno Legacy de XAMPP/InfinityFree.

  • 🔄

    Gestión Dinámica de Caché y URL en Frontend

    Se refactorizó el servicio de cliente ApiService.getAvatarUrl asegurando que las imágenes que consumen la data del API muestren dinámicamente el prefijo o la URL completa basada en el host (local o tunnel prod). Además se solucionó el bug de no actualización in-app de la imagen insertando un Timestamp de recarga sobre la previsualización HTML: ?t=Date.now() en el modal multi-pestaña del Dashboard antiguo, refrescando instantáneamente al guardar el cambio.

⚡ 2. Migración del Footer a Estructura React Micro-Frontend Completado

  • 🧩

    Componente Footer Standalone

    Se creó el punto de montaje footer-mount.jsx. Este archivo se empaqueta junto a Esbuild con todo el react-router como contenedor Wrapper IIFE para habilitar inyección estática en <div id="react-footer-root"></div> a través del script js/react-footer.bundle.js.

  • 🤖

    Automatización y PowerShell (Script de Migración)

    Se programó el script centralizado migrate_footer.ps1 que automatiza la búsqueda de los archivos .html en la carpeta web_page/pages/public/. Éste busca masivamente las etiquetas legadas de VanillaJS <jam-footer> y las sustituye por el Root ID de React con la nueva referencia al script del Footer React. Además se encargó de eliminar el obsoleto js/components/Footer.js legado.

🔧 3. Refactorización Git y Empaquetado de Producción Completado

  • 🗑️

    Remediación de Bloqueo Git LFS

    Hubo una incidencia reportada como pre-receive hook declined causada por un zip accidental gigante (assets (2).zip de 122MB) superando el Threshold de 100MB de Github. Se deshizo el commit corrupto con git reset --soft HEAD~1, se expurgó del caché con git rm --cached, se limpió físicamente el servidor con el comando de PowerShell y se agregó permanentemente la regla estricta a .gitignore ignorando todos los *.zip.

  • 📦

    Producción Final React Inyectado

    Se reconstruyeron por compilación (Build) los archivos manifest y paquetes de react con Node, inyectándose satisfactoriamente en los HTML nativos como admin_users.html y se empujaron los cambios actualizados a la rama remota feature/despliegue-infinityfree para CI/CD con éxito.
